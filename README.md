# Sketchie Launch Plan B

13-slide deck for the October 26, 2026 Sketchie launch without brand social accounts: the pitch, the plays, what was dropped and why, leads, launch day hour by hour, the week, daily quotas, kill rules, and the decisions for the final launch run.

The whole deck is `index.html`. Arrow keys, space, or the buttons move between slides. A link ending in `#s5` opens on slide 5.

## Publish on GitHub Pages

1. Create a repository, for example `sketchie-launch-plan-b`, or add a folder to the existing one.
2. Upload `index.html`, `.nojekyll` and this `README.md` to the root.
3. Settings > Pages > Source: Deploy from a branch, Branch `main`, folder `/ (root)`. Save.
4. After about a minute the deck is live at `https://<your-username>.github.io/sketchie-launch-plan-b/`.

## Before sharing

A GitHub Pages site is public to anyone with the URL. The deck names team members and internal decisions. The `noindex` tag keeps it out of search results but does not hide it.
